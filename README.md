# Bello & Blue Events

Production website for Bello & Blue Events Ltd.

## Production
- Live site: https://bello-blue-events.vercel.app
- Vercel project: `bello-blue-events`
- Repository: `DINGZTRADER/bello_blue`
- Branch: `main`
- Contact / WhatsApp: `0777 680 861`

## Stack
Static HTML, CSS and vanilla JavaScript deployed on Vercel. No database or application server is required. The structured quotation flow sends customer briefs directly to WhatsApp.

## Main files
- `index.html` — page structure, content and SEO
- `styles.css` — responsive visual system
- `app.js` — quotation flow and conversion tracking hooks
- `vercel.json` — Vercel/security configuration
- `robots.txt` / `sitemap.xml` — search-engine files
- `assets/` — optimized Bello & Blue images
